# FileHashGUI — портативный EXE для Windows

Программа с русским интерфейсом для хеширования файлов (ГОСТ Р 34.11-94, Стрибог-256/512, SHA-0, SHA-1, SHA-384, SHA-512, MD2, MD5).

## Получение EXE без установки Python на свой компьютер

1. Создайте пустой репозиторий GitHub (Public или Private).
2. Загрузите в корень репозитория `app.py`, `requirements.txt` и папку `.github` со всем содержимым (сохраните путь `.github/workflows/build-windows.yml`).
3. Перейдите на вкладку **Actions**, откройте **Build portable Windows EXE**, нажмите **Run workflow**.
4. Дождитесь успешной сборки, откройте её и скачайте артефакт **FileHashGUI-Windows-Portable**.
5. Распакуйте архив артефакта и запустите `FileHashGUI.exe` двойным щелчком.

На ПК пользователя ничего устанавливать не требуется. GitHub Actions собирает EXE в Windows. Требуются интернет и учётная запись GitHub для сборки. Если зависимость `pygost` по адресу из requirements.txt недоступна, сборка остановится на этапе установки; EXE не появится. Успешная сборка в этой среде не проверялась.

Устаревшие алгоритмы предназначены для совместимости и обучения. Для ГОСТ-94 при сравнении хешей учитывайте набор параметров.
